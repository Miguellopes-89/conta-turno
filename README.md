# conta-turno

Um contador minimalista para acompanhar o tempo de trabalho até à hora de saída.

![Licença MIT](https://img.shields.io/badge/licen%C3%A7a-MIT-4c8b70)

## O que faz

- Mostra o tempo de trabalho efetivo restante.
- Permite definir a hora de saída.
- Permite alterar o início e o fim do intervalo de almoço.
- Guarda os horários no navegador, para não teres de os definir todos os dias.
- Indica claramente quando estás em pausa e quando é hora de sair.
- Apresenta os dias da semana, evidenciando o dia atual.

## Como utilizar

1. Abre `countdown2-refatorado.html` num navegador.
2. Define a hora de saída e, se necessário, o intervalo de almoço.
3. Deixa a página aberta: a contagem é atualizada a cada segundo.

## Tecnologias

HTML, CSS e JavaScript puro. Não requer instalação nem dependências.
